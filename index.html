备份与设备接力

你的记录，只保存在此浏览器

GitHub Pages 只托管网页。计划、笔记、截图和附件不提交给网站服务器；手机与电脑通过你手动传递的完整备份接力。

  1. 离开当前设备前导出完整 JSON 备份，包含文字、截图和已保存的 PDF / 组会附件。
  2. 将文件传到另一设备使用你选择的文件传输方式，保存到手机“文件”或电脑文件夹。
  3. 在另一设备导入打开同一个网址，选择备份，核对摘要后确认恢复，再继续记录。
导入会覆盖当前设备的全部记录，不会合并。切换设备前先导出，避免两端同时修改；导入前也请保留当前设备的备份。首次从本地网页迁移到网址，同样需要导出再导入。
